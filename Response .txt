The real optimization

If your backend sends 50–100 updates/sec, don’t render 50–100 times/sec.

Buffer to animation frames:

const pendingRef = useRef("");
useEffect(() => {
  let raf;
  const flush = () => {
    if (pendingRef.current) {
      setContent(pendingRef.current);
    }
    raf = requestAnimationFrame(flush);
  };
  raf = requestAnimationFrame(flush);
  return () => cancelAnimationFrame(raf);
}, []);

This caps rendering at:

60 FPS

instead of:

100+ renders/sec

and usually eliminates the “frontend lagging behind backend” feeling.
